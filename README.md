## Selected Work

### PokerCoach
AI recommendation engine for poker skill development. Co-founded and led engineering.
* Built the mobile-first React and Tailwind product from zero to launch.
* Pitched to India's largest poker operator and secured a soft $3M commitment.
* Shut it down when India regulated online poker. Clean call, no sunk cost fallacy.

### Axes Genie and Axes Neo &nbsp;·&nbsp; OpenChain Foundation
Two production AI products as founding engineer.
* Genie: an AI crypto trading agent using GPT-4 for market reasoning, Wagmi and Ethers.js for on-chain execution, RainbowKit for wallet UX.
* Neo: a multimodal creative platform orchestrating Stability AI for images, ElevenLabs for voice, and Runway ML for video, coordinated through GPT-4.
* Killed render bottlenecks in real-time blockchain dashboards with virtualization and memoization.

### SoulCompass &nbsp;·&nbsp; [live](https://soulcompass-lemon.vercel.app)
Maps a modern human problem to the Bhagavad Gita verse that answers it.
* Built on the Gemini API with frequency sounds and haptic feedback. No signup, no friction.
* Code to deployed in 48 hours.

### Taksh Education
MERN edtech platform. CTO and co-founder, all engineering solo.
* 100+ active learners, AWS IVS for live classes, Razorpay for payments.
* Built a reusable component library that compounded across every feature after it.

### Client Builds
Full branding and tech delivery for [Tomatello](https://tomatello.com), All About Dips, Zuprano, and [Indian Travel Point](https://indiantravelpoint.com).
* Custom CMS with Firebase Analytics so non-technical teams own their content without touching code.
* Each one shipped, live, and driving sales.
